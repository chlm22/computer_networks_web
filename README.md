# Top-Down Network Lab

An interactive, visual way to learn computer networking.

This project follows the top-down approach of Kurose & Ross's *Computer Networking: A Top-Down Approach* and the topics of the University of Michigan's EECS 489 (Computer Networks). It starts with the applications people use every day and works down through the protocol stack toward the wire.

## What's inside

Interactive labs that explore core networking ideas across the protocol stack:

- **Application layer:** how names, web content and media get delivered
- **Transport layer:** how data arrives reliably, and how senders share a congested network
- **Network layer:** what happens inside routers and how paths are chosen
- **Link layer:** how data is packaged and carried hop by hop

Along the way, the labs connect these ideas to the data structures and algorithms behind them.

## Goals

- Make abstract protocols easy to *see*, with animations of packets moving between devices
- Let learners experiment by changing inputs and watching what happens
- Stay faithful to how real networks behave
- Connect networking concepts back to core computer science fundamentals

## Running it

Open `netstack.html` in any modern browser. No installation or build step is needed.

## Built with

HTML, CSS and JavaScript, with plans to grow into C++ and Python.
